
            Start editing…FilmedIn - Project OverviewVisionFilmedIn is a minimalist, highly performant platform for discovering movies and TV shows. It serves as a personal cinematic vault where users can track what they've watched, curate custom playlists, and discover detailed metadata about almost any title in existence.Unique Selling Proposition (USP)The defining feature of FilmedIn is its AI Wallpaper Engine. For any movie or TV show, users can generate and download high-quality, AI-generated desktop and mobile wallpapers inspired by the aesthetic and vibe of that specific title.Design Philosophy: Ultra-MinimalistWhitespace is key: The UI must breathe. No cluttered grids or heavy boxes.Typography First: Clean, modern sans-serif fonts (e.g., Inter or Geist). Hierarchy is established through font weight and size, not borders.Muted Palette: Deep charcoal background (#0A0A0A), off-white text (#FAFAFA), and subtle muted accent colors.Hidden Complexity: Details (cast, seasons, trivia) are hidden behind sleek tabs or modals. The default view is clean and focused.Tech Stack (100% Free Tier)Framework: Next.js (App Router) + TypeScriptStyling: Tailwind CSS + Shadcn UIDatabase &amp; Auth: Supabase (PostgreSQL)Storage: Supabase Storage Buckets (for AI wallpapers)Movie Data API: TMDB (The Movie Database)AI Image API: Pollinations.ai (Free, URL-based generation)
