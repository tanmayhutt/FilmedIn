FilmedIn - System ArchitectureHigh-Level Data FlowClient Request: User searches for a title or clicks a movie/TV show.Server-Side Render (Next.js): Next.js Server Components fetch data from TMDB API.Caching: Next.js caches TMDB responses (revalidate tag) to ensure instant page loads and zero redundant API calls.User Actions: If a user adds to a playlist or generates a wallpaper, Next.js Server Actions communicate directly with Supabase.AI Wallpaper Pipeline (The "Generate Once, Cache Forever" Strategy)To keep AI generation 100% free and the app blazing fast, we never generate the same wallpaper twice.User clicks "Generate Wallpaper" on the Interstellar page.Next.js Server Action queries Supabase wallpapers table for tmdb_id: 157336.IF EXISTS: Returns the stored Supabase Storage URL. User downloads instantly.IF NOT EXISTS: a. Backend constructs a cinematic prompt based on the movie's genres/overview.b. Backend fetches the image from https://image.pollinations.ai/prompt/{prompt}.c. Backend uploads the returned image blob to Supabase Storage Bucket.d. Backend inserts the new Supabase Storage URL into the wallpapers table.e. Returns the URL to the user.Authentication FlowHandled via @supabase/ssr (Supabase SSR for Next.js App Router).Uses Email/Password authentication.Middleware protects /profile and /playlists routes, redirecting unauthenticated users to /login.
