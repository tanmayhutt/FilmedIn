FilmedIn - Environment &amp; Setup Guide1. PrerequisitesNode.js (v18 or higher)A code editor (VS Code recommended)An Antigravity IDE (for AI-assisted coding)2. Required API Keys &amp; AccountsTMDB API Key (v3):Create account at themoviedb.org.Go to Settings -&gt; API -&gt; Register Developer Key.Supabase Project:Create project at supabase.com.Go to Project Settings -&gt; API.Copy: Project URL, anon key, service_role key.3. Environment Variables (.env.local)Create a .env.local file in the root of the Next.js project:NEXT_PUBLIC_TMDB_API_KEY=your_tmdb_v3_api_key_hereNEXT_PUBLIC_SUPABASE_URL=your_supabase_project_urlNEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_keySUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key # KEEP SECRET, used for storage uploads4. Supabase Storage SetupIn Supabase Dashboard, go to Storage.Create a new public bucket named wallpapers.Ensure the bucket is set to Public (so users can view/download images without auth).
